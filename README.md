# Forge Labs Hub

A concept hub consolidating TheForge Labs (Assay + Anvil), 10XAI's AI Engine
stack, and Consumption Consulting Partners' Advisory practice into one site,
under the TheForge Labs brand.

Static, zero-dependency single-page site — plain HTML/CSS/JS, no build step.

## What's here

- Problem framing, four practices (Assay, Anvil, Engines, Advisory)
- The "Invisible CRM" concept
- A working ROI calculator and AI maturity quiz
- Playbooks/resources, insights, pricing, FAQ
- An "Ask Alfie" scripted chat widget

## Run locally

```
python3 -m http.server 4931
```

Then open http://localhost:4931

## Status

This is a concept/positioning site exploring a possible combined brand. It is
not a replacement for the live production sites (theforgelabs.ai, 10xai.us,
ccpconsulting.ai), which remain the sources of truth for their own products.
